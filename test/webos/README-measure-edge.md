# Measure edge endpoints

Select one visible edge and choose **Measure edge endpoints**. The dialog reports the two endpoints in world coordinates, their signed X/Y/Z differences, and their straight-line distance. Values are in model units, with display rounded to 12 significant digits. The direction of the differences follows the model's internal edge orientation and is not a user-chosen direction. For a curved or closed edge, this is a chord and is not the length along the curve; a closed circle can therefore show zero. The action reads the current scene transform and does not add a model-history operation. It works on selectable OCC and Native Mesh edges with valid endpoints; invalid or absent/multiple selection is reported without modifying the model.

The strict-CSP Chromium regression `measure-edge-browser.test.cjs` uses a local host fixture and tests both engines, transformed coordinates, repeated dialog lifetime, malformed selection, no/multiple selection, the closed-circle caveat, and history preservation. It is not an account or production deployment test. The workflow is inspired by reviewing ArcCAD's inspection tools; the implementation is original to this fork.
